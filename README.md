# Samfunn Test Prep – static web app

Plain static files: no build step, no framework.

## Deploy to Vercel
Option A – CLI
    npm i -g vercel
    cd samfunn-web
    vercel          # first time: log in, accept the defaults (framework: Other)
    vercel --prod   # publish to your production URL

Option B – GitHub
Push this folder to a GitHub repo, then on vercel.com choose Add New → Project → Import the repo.
Framework preset: Other. Build command: none. Output directory: leave empty (the repo root).

## Or deploy to GitHub Pages
1. Create a repo (e.g. `samfunn`) and put these files in the repo root (index.html at the top level).
2. Repo → Settings → Pages → Source: Deploy from a branch → Branch: main, folder: / (root) → Save.
3. After a minute it is live at https://<your-username>.github.io/samfunn/
   (vercel.json is simply ignored there).

## On your iPhone
Open the Vercel URL in Safari → Share → Add to Home Screen. It opens full-screen and works offline.
Progress is saved on each device (in the browser), so iPhone and Mac keep separate progress.

## Updating questions
Replace content.json (generated by the content/ scripts in the Xcode project) and bump CACHE in sw.js
(e.g. samfunn-v2) so installed copies pick up the change.
